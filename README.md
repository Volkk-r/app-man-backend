# Apartment Management API

Самостоятельный backend учебного проекта. Python 3.10+ и SQLite из стандартной библиотеки Python; дополнительные пакеты и отдельный сервер базы данных не нужны.

## Запуск

1. Установите Python 3.10 или новее.
2. В терминале перейдите в папку проекта и выполните:

   ```bash
   python3 app.py
   ```

   В Windows можно использовать `python app.py`.
3. Откройте Swagger: http://localhost:3000/docs

При первом запуске автоматически создаются папка `data`, база `apartments.sqlite3`, папка фотографий `uploads` и секрет подписи токенов. Данные сохраняются между запусками. Для остановки нажмите Ctrl+C. Для переноса данных сохраняйте всю папку `data`.

Swagger UI загружается с CDN, поэтому для страницы `/docs` нужен интернет. Сам API и описание `/openapi.json` работают локально без интернета.

## Как начать работу

1. В Swagger вызовите `POST /auth/register`, указав `name`, `email` и пароль от 8 символов. Или войдите через `POST /auth/login`.
2. Скопируйте `token` из ответа. Нажмите **Authorize**, вставьте токен и подтвердите.
3. Вызовите `POST /apartments` с `{}`, чтобы создать пустой черновик. Запомните его `id`.
4. Заполните поля через `PATCH /apartments/{apartmentId}`, загрузите фотографии через `POST /apartments/{apartmentId}/images` (поле `images`) и отправьте `{"status":"published"}` через endpoint статуса.

Для frontend передавайте заголовок `Authorization: Bearer <token>`. Токен действует 7 дней. Формат изображений в ответах: `{id, url, isCover}`. `url` — относительный путь, для отображения добавьте адрес сервера, например `http://localhost:3000`.

## Правила данных

- В черновике строковые поля по умолчанию пустые, числовые — `null`, удобства — пустой массив. Поля правил по умолчанию заполнены пустым временем и `false`.
- PATCH изменяет только переданные поля; вложенный объект `rules` также обновляется частично. `ownerId`, `status`, `images` и служебные поля через него изменить нельзя.
- Числовые значения неотрицательны; гости, комнаты, кровати и цена при публикации должны быть больше нуля. Площадь при публикации также должна быть больше нуля; ванные комнаты и этаж могут быть равны нулю. Целые характеристики передаются целыми числами. При необходимости очистить числовое поле отправьте `null`.
- Время правил, если указано, передаётся как `HH:MM`. При публикации правила и удобства необязательны.
- Загрузка: поле `images`, до 10 изображений на квартиру, каждое не более 5 МиБ. Сервер проверяет тип и сигнатуру JPEG, PNG или WebP. Первая фотография становится главной.
- Фотографии доступны по прямой ссылке без авторизации, чтобы их можно было отображать через обычный `<img>`. Имена файлов случайные; API черновиков и архивных квартир защищён. Не загружайте конфиденциальные изображения.
- Опубликованную квартиру можно получить без токена. Для просмотра черновика или архива нужен токен владельца. Список `/apartments/my` содержит `coverImage` (объект фотографии или `null`).
- Допустимые переходы: черновик → опубликовано → архив → опубликовано. При публикации возвращаются ошибки по каждому незаполненному полю.

## Настройка

При необходимости задайте переменные окружения `PORT` (по умолчанию 3000), `DATA_DIR` (путь к папке данных) и `JWT_SECRET` (секрет JWT). По умолчанию секрет создаётся автоматически и хранится в папке данных. Сервер слушает только `127.0.0.1` и предназначен для локальной учебной разработки, а не публикации в интернете.
